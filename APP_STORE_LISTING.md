# App Store Listing Materials

## App Information

### App Name
**Protein & Calorie Tracker**

### App Description

Track your daily protein intake with automatic calorie calculation. This simple, intuitive app helps you maintain healthy nutrition habits with a clean, user-friendly interface designed specifically for iOS.

**Key Features:**
• Easy protein tracking with auto-calculated calories (4 cal/gram)
• Visual summary of your progress
• Complete history of all entries
• Simple and intuitive design
• Optimized for all iPhone sizes
• Dark mode support

Whether you're building muscle, losing weight, or simply maintaining a healthy lifestyle, Protein & Calorie Tracker makes monitoring your nutrition effortless by automatically calculating calories from your protein intake.

### Build Configuration Notes

**Required Xcode Settings**:
1. Set Build Configuration to "Release"
2. Ensure Bundle Identifier is unique (e.g., com.company.proteincalorietracker)
3. Set Version to 1.0 and Build to 1
4. Configure Code Signing with valid distribution certificate
5. Archive and validate app before submission

**App Icons Required**:
- 1024x1024px App Store icon (no transparency, RGB color space)
- The universal icon set in Assets.xcassets supports all device sizes automatically
