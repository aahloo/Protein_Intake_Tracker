# iOS App Submission Project Rubric

This rubric outlines the evaluation criteria and submission requirements for the iOS protein and calorie tracking app project.

---

## 1. iOS Project Refinement

### Criteria / Submission Requirements

**The app's user interface adheres to Apple's Human Interface Guidelines.**

#### Requirements:
- All interface elements must conform to Human Interface Guidelines
- Visual consistency is maintained throughout the app

#### Evaluation Points:
- [ ] Navigation patterns follow iOS conventions
- [ ] Typography and spacing comply with HIG standards
- [ ] Color schemes and contrast ratios meet accessibility requirements
- [ ] Interactive elements (buttons, controls) use standard iOS components appropriately
- [ ] Layout adapts properly to different screen sizes
- [ ] Visual hierarchy is clear and consistent across all views

---

## 2. Xcode Project Configuration

### Criteria / Submission Requirements

#### **Xcode project build settings are correctly configured for release.**

**Requirements:**
- The build configuration and targets are set for release

**Evaluation Points:**
- [ ] Active scheme is set to Release configuration
- [ ] Optimization level is appropriate for distribution
- [ ] Debug symbols are handled correctly
- [ ] Code signing is properly configured

#### **Xcode project property list is complete with accurate keys and values.**

**Requirements:**
- All required keys and values in Info.plist are verified and correct

**Evaluation Points:**
- [ ] Bundle identifier is unique and follows reverse-DNS format
- [ ] Version and build numbers are set correctly
- [ ] Required privacy usage descriptions are included (if applicable)
- [ ] Supported interface orientations are specified
- [ ] Launch screen configuration is present
- [ ] All necessary capability keys are included

#### **Xcode project assets are configured and stored correctly.**

**Requirements:**
- App icons and visual assets are correctly placed and meet required specifications

**Evaluation Points:**
- [ ] App icon set includes all required sizes (1024x1024 for App Store, plus device-specific sizes)
- [ ] Icons are placed in the Assets.xcassets catalog
- [ ] Icons meet Apple's design specifications (no transparency, proper format)
- [ ] Launch screen assets are properly configured
- [ ] All image assets use appropriate resolutions (@1x, @2x, @3x)

---

## 3. App Store Listing

### Criteria / Submission Requirements

#### **The app name and description conform to Apple guidelines and best practices.**

**Requirements:**
- The app name and description are clear, concise, and highlight the app's benefits and value to potential users

**Evaluation Points:**
- [ ] App name is unique, memorable, and under 30 characters
- [ ] App name doesn't include generic terms or violate trademark guidelines
- [ ] Description clearly explains what the app does
- [ ] Description highlights key features and benefits
- [ ] Description is free of grammatical errors and typos
- [ ] Promotional text (if used) is compelling and appropriate

#### **Screenshots highlight key app functionality and conform to Apple's guidelines for size and multiple devices.**

**Requirements:**
- Screenshots and app previews show the app's functionality
- At least 6 screenshots are present for different iPhone screen sizes

**Evaluation Points:**
- [ ] Minimum of 6 screenshots provided per device size category
- [ ] Screenshots showcase primary app functionality
- [ ] Screenshots display actual app interface (not marketing graphics)
- [ ] Screenshots are in correct dimensions for each device type:
  - 6.7" display (iPhone 14 Pro Max, 15 Plus, 15 Pro Max)
  - 6.5" display (iPhone 11 Pro Max, XS Max)
  - 5.5" display (iPhone 8 Plus, 7 Plus, 6s Plus)
- [ ] Screenshots are high-quality and properly formatted
- [ ] Screenshots follow a logical sequence showing user flow

#### **Keywords are related to the app and conform to Apple's guidelines and best practices.**

**Requirements:**
- Keywords are relevant and likely to improve app discoverability

**Evaluation Points:**
- [ ] Keywords are directly related to app functionality
- [ ] Keywords do not include app name or company name
- [ ] Keywords are comma-separated (no spaces except within phrases)
- [ ] Keywords stay within the 100-character limit
- [ ] Keywords avoid trademark violations
- [ ] Keywords target likely user search terms
- [ ] No duplicate or redundant keywords included

---

## 4. App Store Connect

### Criteria / Submission Requirements

**Complete and accurate App Store Connect information is provided.**

#### Requirements:
- Pricing and availability details are correctly entered
- Privacy, age-rating, and content descriptions are accurately provided
- All app-specific information required for review is included

#### Evaluation Points:

**Pricing and Availability:**
- [ ] Pricing tier is selected
- [ ] Available territories/countries are specified
- [ ] Availability date is set (if applicable)

**App Privacy:**
- [ ] Data collection practices are disclosed
- [ ] Privacy policy URL is provided (if required)
- [ ] Data usage is accurately described
- [ ] Third-party data sharing is disclosed (if applicable)

**Age Rating and Content:**
- [ ] Age rating questionnaire is completed accurately
- [ ] Content warnings are appropriate for the app
- [ ] Age rating reflects actual app content

**Review Information:**
- [ ] Contact information for Apple reviewers is provided
- [ ] Demo account credentials are included (if app requires login)
- [ ] Special instructions for reviewers are clear and complete
- [ ] Notes explain any non-obvious functionality

---

## Submission Checklist

Before final submission, verify that ALL of the following are complete:

- [ ] All UI elements comply with Apple's Human Interface Guidelines
- [ ] Build configuration is set to Release
- [ ] Info.plist contains all required keys and values
- [ ] App icons and assets are properly configured
- [ ] App name and description are compelling and guideline-compliant
- [ ] At least 6 screenshots per device size are uploaded
- [ ] Keywords are relevant and properly formatted
- [ ] Pricing and availability information is complete
- [ ] Privacy information is accurately disclosed
- [ ] Age rating is appropriate and complete
- [ ] Review information and demo credentials are provided

---

## Grading Scale

### Excellent (90-100%)
All criteria are met with exceptional quality. App demonstrates professional polish, complete documentation, and thorough attention to Apple's guidelines.

### Proficient (80-89%)
All major criteria are met. Minor improvements could be made in polish, documentation, or guideline adherence.

### Developing (70-79%)
Most criteria are met, but significant gaps exist in one or more areas. App needs revision before submission.

### Incomplete (Below 70%)
Multiple critical criteria are not met. App requires substantial work before it's ready for App Store submission.
